# 낑꿍깡꿍 캘린더 💕

GitHub Pages에서 실행할 수 있도록 구성한 정적 HTML 캘린더입니다.

## GitHub에 올리는 방법

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 `index.html`, `.nojekyll`, `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.
6. 잠시 기다리면 Pages 설정 화면에 사이트 주소가 표시됩니다.

## 비밀번호

첫 화면에서 **💕 들어가기**를 누르면 비밀번호를 입력해야 합니다. 설정된 비밀번호는 `260510`입니다. 이 기능은 화면 진입을 가볍게 막는 용도이며, 비밀번호가 HTML 코드 안에 들어 있어 개발자 도구로 확인할 수 있습니다. 민감한 정보 보호가 필요한 경우에는 실제 서버 측 인증을 설정해야 합니다.

## 꼭 알아둘 점

현재 파일은 `USE_DB=false`로 설정되어 있어 **테스트/로컬 모드**로 동작합니다. 투두, 일정, 기념일, 일기, 사진, 한마디는 현재 브라우저 메모리에서만 유지되며 페이지를 새로고침하거나 다시 열면 사라질 수 있습니다. GitHub에 업로드하는 것만으로 데이터가 저장되거나 두 사람이 실시간 공유되지는 않습니다.

데이터를 계속 저장하고 연인과 공유하려면 별도의 데이터베이스/백엔드 연결과 접근 권한 설정이 필요합니다. 공개 저장소에는 비밀번호, API 비밀키 또는 개인 데이터를 올리지 마세요.
